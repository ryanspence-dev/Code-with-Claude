This project is a Python score calculator built step by step as a learning exercise. It asks the user to type in a series of scores between 0 and 100, one at a time, and when they're done it displays a summary including the average score, the highest and lowest scores, how many passed or failed, and an overall letter grade. It uses Python and nothing else — no external libraries or frameworks, just Python's built-in features. To run it, you simply type "python score_calculator.py" in the terminal; there is no build step, no install, and no tests. The repository keeps all the earlier versions of the program alongside the current one, so you can see how it grew from a basic script with no safety checks into a polished tool that handles bad input gracefully and shows detailed results.
